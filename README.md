# Sergio Ramirez's Portfolio
This project is my final portfolio website for Code the Dream's Intro to Web Development course.

## About the Project
This portfolio showcases my background in sales, UX research, recruitment, and web development. It also includes a soccer dashboard that retrieves soccer data from a public API.

## Technologies Used
- HTML
- CSS
- JavaScript
- GitHub API
- API-Football

## Features
- About section
- Experience section
- Skills
- GitHub projects through the GitHub API
- Leave a Message form
- Removable messages
- Soccer matches dashboard
- Premier League standings dashboard

## Open API Page
The Soccer Dashboard uses API-Football to get:
1. Soccer matches
2. Premier League standings
The two buttons make separate GET requests to the API.

## How to View Project
Open `index.html` in a web browser.
To view the soccer dashboard, select the Soccer Dashboard link in the portfolio navigation bar.
